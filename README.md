# NAMU — Studio & Social Music (Messages Fix)

Αλλαγές που έγιναν στα Messages (`index.html`):
1. Όταν μπαίνεις στα Messages και το πεδίο αναζήτησης είναι κενό, δεν εμφανίζεται πλέον από κάτω η λίστα «All Users» — εμφανίζονται μόνο οι ενεργές συνομιλίες (`Active Chats`) αν υπάρχουν, ενώ όλοι οι χρήστες εμφανίζονται μόνο όταν κάνεις αναζήτηση.
2. Στην αναζήτηση μηνυμάτων περιλαμβάνονται τόσο τα 3 βασικά προφίλ όσο και όλοι οι λογαριασμοί που συνδέονται με email (`profiles`, `messages`, `Task` και τοπικά registries), ώστε όλοι να μπορούν να στέλνουν μήνυμα σε όλους.
