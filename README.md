# NAMU — Studio & Social Music (v2)

Αλλαγές που έγιναν στο `index.html`:
1. **Κεντρική αναζήτηση**: Εμφανίζει πλέον μόνο τραγούδια (`Search tracks...`) — αφαιρέθηκαν τα `Matching Profiles` από την κεντρική σελίδα, ώστε η αναζήτηση προφίλ να γίνεται αποκλειστικά μέσα στα Messages.
2. **Messages (κενή αναζήτηση)**: Όταν μπαίνεις στα Messages και δεν έχεις πληκτρολογήσει όνομα, δεν εμφανίζεται απολύτως τίποτα κάτω από το πεδίο αναζήτησης — εμφανίζονται αποτελέσματα μόνο όταν γράφεις όνομα.
3. **Όλοι οι λογαριασμοί με email**: Κάθε χρήστης που κάνει εγγραφή ή σύνδεση με email αποθηκεύεται και ανακτάται αυτόματα (από `profiles`, `messages`, `Task` και local registry) ώστε όλοι να μπορούν να βρίσκουν και να στέλνουν μήνυμα σε όλους.
